# Vedang Planets App

A JavaFX 3D educational application for ARM64 Linux.

## Features

- JavaFX 3D
- ARM64 support
- Debian package
- Open source under the MIT License

## Requirements

- ARM64 (AArch64)
- Java 17 or later
- JavaFX Runtime (if not bundled)

## Installation

### Using the Debian package

```bash
sudo dpkg -i VedangPlanetsApp_1.0_arm64.deb
sudo apt -f install
```

### Running from JAR

```bash
java -jar VedangPlanetsApp.jar
```

## Building

```bash
javac ...
jar ...
```
